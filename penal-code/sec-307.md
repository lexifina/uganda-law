# 307. Attempt to set fire to crops, etc.
Any person who—
(a) attempts unlawfully to set fire to any thing as is mentioned in section 306; or
(b) wilfully and unlawfully sets fire to anything which is so situated that any thing as is mentioned in section 306 is likely to catch fire from it,
commits a felony and is liable, on conviction, to imprisonment for a term of seven years.
